## React Query Builder Expo Example

[![Open in Expo Snack](https://img.shields.io/badge/Open_in-Expo_Snack-000020?logo=expo)](https://react-querybuilder.js.org/sandbox?p=snack&t=native-expo)

Click the link above to open this example as an online, editable demo on [Expo Snack](https://snack.expo.dev) (runs in the browser, iOS/Android simulators, or on your own device via [Expo Go](https://expo.dev/go)), or clone it locally with [degit](https://www.npmjs.com/package/degit):

```bash
npx degit github:react-querybuilder/react-querybuilder/examples/native-expo rqb-example-native-expo
cd rqb-example-native-expo
npm install
npm start
```

Then scan the QR code with Expo Go, or press `i` (iOS simulator), `a` (Android emulator), or `w` (web).

This example uses the default native components provided by `QueryBuilderNative` (`defaultNativeControlElements`) on iOS/Android and switches to `defaultNativeWebControlElements` when running on the web. For a browser-only setup using Vite and `react-native-web`, see the [native example](../native/).
